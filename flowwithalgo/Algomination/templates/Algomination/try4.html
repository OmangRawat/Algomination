~Algorithms with Animation

Purpose

Everyone likes tinkering with things that are considered out of syllabus so this project is just a result of tinkering with Web Development stuff for learning and finding some interesting libraries like anime.js and using it to bring up a project that will be helpful for both, the creators to showcase their Development work as a collection, and learners to understand the algorithms with fun animations and get some similar projects to learn from to build up their own fragments to showcase a new algorithm with animations to help other similar developers and find some friends along the way. This project is a collective project for everyone and anyone can contribute to the project by mailing us their self made similar animated algorithms with the GitHub link of the piece. Ofcourse every project added will be given adequate credits for their projects and added to the list of contributors. We would love to have people adding their creations to this project to help make a wonderful database of Algorithms and a great community of developers and learners.

How to send us your projects

  • Check if the algorithm you wanna make has not already been made by someone else
  • You shuld have a GitHub account
  • Upload your project as a GitHub Repo and publish at GitHub Pages
  • Send Us the link and your details in the Contact Form
  • For any help Contact Us on our Email ID

Algorithms

An algorithm is any well-defined computational procedure that takes some value, or set of values, as input and produces some value, or set of values, as output. An algorithm is thus a sequence of computational steps that transform the input into the output. An algorithm can be specified as a computer program, or even as a hardware design. The only requirement is that the specification must provide a precise description of the computational procedure to be followed.An algorithm is an explicit, precise, unambiguous, mechanically-executable sequence of elementary instructions, usually intended to accomplish a specific purpose.
